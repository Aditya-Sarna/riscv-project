ARCHITECTURE SUMMARY
===============================================================================

PROCESSOR CORE:
- Architecture: RISC-V RV64I base + Zba extension
- Pipeline: 5 stages (IF, ID, EX, MEM, WB)
- Data width: 64-bit
- Instruction width: 32-bit
- Register file: 32 x 64-bit registers (x0 hardwired to zero)
- Memories: Separate 4KB IMEM + 4KB DMEM (Harvard architecture)

PIPELINE STAGES:
1. IF  (Instruction Fetch)  - PC, IMEM access, PC+4
2. ID  (Instruction Decode) - Decoder, register file read, Zba check
3. EX  (Execute)            - ALU, Zba operation selection
4. MEM (Memory Access)      - DMEM read/write
5. WB  (Write Back)         - Result mux, register file write

ZBA EXTENSION:
- Custom opcode: 0x7F (for demonstration)
- Format: R-type (funct7 | rs2 | rs1 | funct3 | rd | opcode)
- Operation: AG_ADD (funct7=0x12) performs rd = rs1 + rs2
- Purpose: Address generation via addition
- Implementation: Decoded in EX stage, uses ALU

RV64I INSTRUCTIONS IMPLEMENTED:
- ADD, SUB (R-type, opcode 0x33)
- ADDI (I-type, opcode 0x13)
- LD (load doubleword, opcode 0x03)
- SD (store doubleword, opcode 0x23)
- JAL (jump and link, opcode 0x6F)

BUILD INSTRUCTIONS
===============================================================================

PREREQUISITES:
1. RISC-V GNU Toolchain (riscv64-unknown-elf-*)
2. SystemVerilog simulator (Questa, VCS, or Icarus)
3. Optional: Draw.io CLI for diagram generation

QUICK BUILD:
$ make hex           # Generate imem.hex from test.c
$ make sim           # Run simulation
$ make diagram       # Generate design_diagram.pdf

MANUAL BUILD:
$ riscv64-unknown-elf-gcc -march=rv64i -mabi=lp64 -O0 -nostdlib \
    -Ttext=0x0 software/test.c -o software/test.elf
$ riscv64-unknown-elf-objcopy -O binary software/test.elf software/test.bin
$ hexdump -v -e '1/4 "%08x\n"' software/test.bin > rtl/imem.hex

SIMULATE:
$ vlog rtl/*.sv tb/tb_processor.sv        # Questa/ModelSim
$ vsim -c tb_processor -do "run -all; quit"
